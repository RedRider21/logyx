# docs

Cartella per i documenti di riferimento e i promemoria esportati (es. il "Logyx — Documento di Design"
esportato in `.md` e `.pdf` dal documento online).

Puoi spostare qui liberamente i file esportati: git li versiona insieme al resto del progetto, così restano
con te quando copi o cloni la cartella su un altro PC.
